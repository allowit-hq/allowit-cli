AllowIt: policy wallets for agents. Go on. On your terms.

Usage: allowit [OPTIONS] [COMMAND]

Examples:
  allowit rail use <rail>
  allowit keys generate agent
  allowit exec --op transfer --to DESTINATION --amount ASSET:5
  allowit status pay-0001 --wait 60s

Commands:
  keys        Manage local keys and select the signing key
  rail        List rails, show what a rail supports and choose the current rail
  config      Show the configuration and where it lives
  wallet      Select and inspect installed policy wallets
  policy      Generate and validate portable policies or inspect an installed policy
  exec        Submit an agent request: the policy checks it and the rail settles it
  status      Read a request's state. The local journal supplies its rail and wallet; --rail and
              --wallet are the fallback
  history     List recent requests from the local journal
  completion  Print a shell completion script
  guide       Print the agent guide: the commands in the order an agent uses them
  version     Print the version and the git revision of the build
  help        Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
  -n, --rail <RAIL>       Rail identifier or alias from rail ls [env: ALLOWIT_RAIL] [alias:
                          --network]
      --wallet <ADDR>     Wallet address accepted by the selected rail [env: ALLOWIT_WALLET]
      --json              Print JSON instead of text
  -y, --yes               Confirm destructive actions without a prompt
  -q, --quiet             Print no progress on stderr
  -v, --verbose           Print the resolved rail, wallet and config directory on stderr
      --no-color          Disable color (NO_COLOR also disables it)
      --config-dir <DIR>  Config directory [default: $XDG_CONFIG_HOME/allowit or ~/.config/allowit]
                          [env: ALLOWIT_CONFIG_DIR]
      --rpc-url <URL>     RPC URL override for the selected rail

Exit codes:
  0 ok, 1 internal error, 2 usage error, 3 configuration or not supported on
  this rail, 4 rejected by the contract or refused by the server, 5 uncertain
  (retry with the same ID), 6 replayed, 7 network unavailable (retry with the
  same ID), 10 owner signature needed, 11 waiting for owner input, 12 pending,
  20 denied by the policy, 130 interrupted
