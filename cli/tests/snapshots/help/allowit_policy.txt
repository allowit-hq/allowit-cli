Generate and validate portable policies or inspect an installed policy

Usage: allowit policy [OPTIONS] <COMMAND>

Examples:
  allowit policy kinds
  allowit policy check policy.rs
  allowit policy check policy.rs --compile
  allowit policy show --source

Commands:
  owner-status  Read original owner transaction receipts
  deploy        Deploy a reviewed policy and executable
  fund          Fund the selected policy wallet
  activate      Approve exact policy source and parameters
  export        Verify and cache the active public profile
  params        Show or change the typed values of an unsigned draft
  revise        Revise an unsigned draft in the owner's words; prints the next draft
  update        Change values of an active wallet with one owner signature; usage and nonce stay
  verify        Compare a wallet document with the ledger and read the wallet state back
  export-pair   Print what the server evaluates and what the wallet enforces for a policy
  kinds         List the wallet kinds of the selected rail: what enforces the policy and what holds
                the funds
  generate      Generate a portable draft through the owner-authenticated server; does not deploy or
                spend
  show          Show the wallet's installed policy
  check         Validate the structure and allowed operations of portable Rust source
  help          Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

Global options:
  -n, --rail <RAIL>       Rail identifier or alias from rail ls [env: ALLOWIT_RAIL] [alias:
                          --network]
      --wallet <ADDR>     Wallet address accepted by the selected rail [env: ALLOWIT_WALLET]
      --json              Print JSON instead of text
  -y, --yes               Confirm destructive actions without a prompt
  -q, --quiet             Print no progress on stderr
  -v, --verbose           Print the resolved rail, wallet and config directory on stderr
      --no-color          Disable color (NO_COLOR also disables it)
      --config-dir <DIR>  Config directory [default: $XDG_CONFIG_HOME/allowit or ~/.config/allowit]
                          [env: ALLOWIT_CONFIG_DIR]
      --rpc-url <URL>     RPC URL override for the selected rail
